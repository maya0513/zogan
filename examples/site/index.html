01 / Why

A small contract at the HTML boundary.

One URL has one representation. A Page is a document, a Fragment has its own route, and an Island has an explicit owner. There is no second navigation model for the server and browser to keep synchronized.

Your application owns
routes, data, authorization, mutations, domain state
The browser owns
links, forms, redirects, navigation, history
zogan owns
HTML response factories, explicit markers, activation scheduling
02 / Model

Four explicit boundaries. Nothing hidden.

Each primitive has one job. A route composes only the boundaries it needs.

C

Cache

Every HTML response requires an opaque, validated CachePolicy.

publicCache({ sMaxAge: 60 })
P

Page

A complete document with a doctype and an optional application layout.

zogan.page(c, view, { cache })
F

Fragment

Raw HTML from a dedicated route, placed into one explicit FragmentSlot.

<FragmentSlot src="/fragments/cart" />
I

Island

Server fallback, JSON props, and a typed component loaded on its trigger.

<Island of={counter} props={...} />
03 / Explicit contract

Declare first.
Enhance second.

Cache behavior, fragment targets, Island ownership, and lazy component lookup are visible in application code. If an enhancement cannot prove its contract, the server-rendered fallback stays in place.

  1. 01 one ordinary Hono route per representation
  2. 02 CachePolicy required for every HTML response
  3. 03 root-relative, same-origin Fragment source
  4. 04 plain JSON object for Island props
  5. 05 exact descriptor ID to lazy-loader ID
04 / Quick start

Two response factories. Ordinary routes.

Install the shared runtimes, declare cache behavior at each response, then add only the FragmentSlots and Islands the page needs.

$ pnpm add zogan hono preact
server.tsxexplicit HTML routes
import { Hono } from "hono";
import {
  createZogan, FragmentSlot,
  privateNoStore, publicCache,
} from "zogan";

const app = new Hono();
const zogan = createZogan({
  layout: Layout,
});

app.get("/", (c) => zogan.page(
  c,
  <FragmentSlot
    as="span"
    src="/fragments/cart"
  >
    <a href="/cart">Cart —</a>
  </FragmentSlot>,
  { cache: publicCache({ sMaxAge: 60 }) },
));

app.get("/fragments/cart", (c) =>
  zogan.fragment(c, <a href="/cart">Cart 2</a>, {
    cache: privateNoStore({ vary: ["Cookie"] }),
  }),
);

HTML
The baseline

Links and forms are the application.

Complete Pages, native form actions, redirects, and browser history work without JavaScript. FragmentSlot children and server-rendered Islands remain useful if scripts are delayed, disabled, or fail. Enhancement is an explicit layer, never the entrance.
